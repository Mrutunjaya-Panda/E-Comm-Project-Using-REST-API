# 🛒 E-Commerce REST API

A scalable backend API built with **Node.js & Express** for managing an e-commerce platform.  
This project demonstrates real-world backend concepts including authentication, cart management, product handling, and API documentation.

---

## 🚀 Features

- 📦 Product Management (CRUD operations)
- 👤 User Authentication (SignUp / SignIn)
- 🔐 Secure APIs using JWT Authentication
- 🛒 Cart Management (Add / Remove Items)
- ⭐ Product Rating System
- 📄 API Documentation using Swagger

---

## 📚 API Documentation (Swagger V2.0)

This project includes API documentation using **Swagger V2.0**, making it easier for clients and developers to understand and test APIs.

### 🔍 What is Swagger? (Layman Explanation)

> Swagger is like a **menu for your API** 🍽️  
> It shows what endpoints are available, what data to send, and what response to expect — all in a simple UI.

Instead of reading code, anyone can:
- See all APIs in one place  
- Try them directly from the browser  
- Understand request/response formats  

---

### ⚙️ What Swagger Does (Technical View)

- Provides **interactive API documentation**
- Defines API structure using JSON/YAML
- Allows testing endpoints without external tools (like Postman)
- Improves collaboration between frontend & backend developers
