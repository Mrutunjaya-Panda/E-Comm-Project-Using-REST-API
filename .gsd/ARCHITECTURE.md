## Data Flow

1. **Client Request:** Incoming HTTP request hits `server.js`.
2. **Middleware Processing:** Processed by `cors`, `body-parser`, `loggerMiddleware`.
3. **Authentication:** Protected routes pass through `jwtAuth` middleware which sets `req.userId`.
4. **Routing:** Request is routed to specific feature routers (`/api/products`, etc.).
5. **Controller:** Controller validates input, calls repository functions.
6. **Repository Layer:** Repository executes Mongoose operations (find, aggregate, populate).
7. **Database:** MongoDB processes the query and returns data.
8. **Response:** Controller formats the data/errors (using `ApplicationError`) and returns the JSON response.
