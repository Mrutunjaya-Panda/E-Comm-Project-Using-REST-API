Tech Stack

⚡

Node.js

Async, non-blocking runtime powering the entire API.

🚀

Express.js

Minimal web framework for routing & middleware chaining.

🍃

MongoDB

Flexible document store for products, users, orders & likes.

🔗

Mongoose

ODM powering schemas, relationships & polymorphic refs.

🔐

JWT

Stateless auth tokens verified on every protected route.

🔒

Bcrypt

Salts & hashes passwords before they touch the database.

📄

Swagger UI

Live OpenAPI 3.0 docs served at /api-docs.

📁

Multer

Multipart file uploads for product images.

📊

Winston

Structured JSON request & error logging.

🛡️

CORS

Restricts cross-origin access to allowed clients.

🔧

Dotenv

Keeps DB_URL & JWT_SECRET out of source control.

🌿

ES Modules

Modern import/export with "type": "module".

API Modules

🛍️ Products

CRUD operations, category management, product ratings, reviews, and image uploads.

👤 Users

Secure JWT authentication, user signup, signin, password reset, and role-based access.

🛒 Cart

Add/remove items, view active cart, and dynamic quantity management.

📦 Orders

Convert cart items to placed orders, maintain history and track order status.

❤️ Likes

Polymorphic like/unlike system for products and view user's liked items.

Architecture Flow

📱 Client Request HTTP request
→
🛡️ CORS Origin allow-list
→
📦 Body Parser JSON parsing
→
📊 Logger Winston request log
→
🔐 JWT Middleware Token verification
→
🛣️ Route Handler Express router
→
🎮 Controller Business orchestration
→
🗄️ Repository Data-access layer
→
🍃 MongoDB Mongoose models

⚠️ Errors thrown anywhere bubble up to a centralized error-handling middleware → JSON response.

Key Features

⚡

Modular Architecture

Feature-first folders — product, user, cart, order, like.

🔐

JWT Authentication

Stateless Bearer tokens, payload injected into req.userId.

🔒

Bcrypt Hashing

Passwords salted & hashed — never stored in plaintext.

🏗️

Repository Pattern

Data access decoupled from controllers in every feature.

🚨

Global Error Handling

Custom ApplicationError + centralized error middleware.

📊

Winston Logger

Structured JSON logs; credentials redacted on auth routes.

📁

File Upload

Multer with sanitized, timestamped filenames.

🛡️

CORS Configured

Origin-restricted cross-origin policy via options object.

🔀

Invalid Route Handler

Uniform 404 JSON responses for unknown paths.

📄

Swagger OpenAPI 3.0

Interactive, self-documenting API at /api-docs.

🌿

ES Modules

Native import/export — modern module system.

✅

Schema Validation

Email regex, password strength, enums & min constraints.

❤️

Polymorphic Likes

refPath references Product & Category in one schema.

🧬

Mongoose Middleware

pre/post save & find hooks for auditability.

💾

DB Relationships

1:N reviews, M:N categories, and transactional orders.
