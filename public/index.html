E-Commerce REST API

Production-ready backend built with Node.js, Express & MongoDB

Explore API Docs → View on GitHub →

Tech Stack

Node.js Express.js MongoDB Mongoose JSON Web Token (JWT) Bcrypt Swagger UI Multer Winston Logger CORS Dotenv

API Modules

🛍️ Products

CRUD operations, category management, product ratings, reviews, and image uploads.

👤 Users

Secure JWT authentication, user signup, signin, password reset, and role-based access.

🛒 Cart

Add/remove items, view active cart, and dynamic quantity management.

📦 Orders

Convert cart items to placed orders, maintain history and track order status.

❤️ Likes

Polymorphic like/unlike system for products and view user's liked items.

Architecture Flow

Client Request→ JWT Middleware→ Route Handler→

Controller→ Repository→ MongoDB

Key Features

  • Feature-based modular architecture
  • JWT Authentication & Authorization
  • Global Error Handling with custom ApplicationError
  • Request logging with Winston
  • File upload support with Multer
  • Invalid route handling (404)
  • Swagger/OpenAPI 3.0 Documentation
  • CORS configured

Future Implementations

  • Email notifications (NodeMailer)
  • Rate limiting & request throttling
  • Admin dashboard
  • Product search & filters
  • Wishlist feature
